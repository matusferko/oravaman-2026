# Oravaman 2026 — Plán prípravy

6-týždňový tréningový plán pre XTRI Oravaman (React + Vite).

## Vývoj

```bash
npm install
npm run dev
```

Otvor [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

Statický výstup je v `dist/` — vhodné na GitHub Pages alebo ľubovoľný statický hosting.

## Štruktúra

- `src/data/plan.ts` — týždne, dni a pretekové disciplíny
- `src/components/` — UI komponenty
- `public/chart.png` — graf objemu zo Stravy
- `index.legacy.html` — pôvodná jednostránková verzia (referencia)
